# Frontend (`src/Web/frontend`)

## 1. Tech stack

- React 19 + TypeScript 6 + **Vite 8** (rolldown), linted with **oxlint**
- Tailwind CSS v4 (`@tailwindcss/vite`), Framer Motion, lucide-react
- Zustand (auth token), TanStack Query + @dnd-kit (admin only), plain `fetch`
- React Router DOM v7

## 2. Structure

```
src/
├── main.tsx                 # hydrates prerendered pages; reloads once if an old chunk is gone after a deploy
├── App.tsx                  # Routes: /, /vi, /privacy, /projects/:slug (+ /vi), /login, /dashboard/* (lazy)
├── index.css                # Tailwind + the site's colour / font tokens (shared with the admin console)
├── content/                 # portfolio.json + projects.json: written from the API at build time
├── pages/public/            # Home, ProjectPage, Privacy, NotFound
├── components/
│   ├── public/              # Navbar, Hero, About, ProjectsSection, ProjectsBento (experience), Now, Contact, Footer
│   ├── admin/               # admin console: AdminLayout, api.ts, ui.tsx, form.ts, publish.ts, pages/*
│   ├── ui/                  # Badge, Button, Card, Input (public site)
│   └── CatChatbot.tsx       # Sigma Cat widget, reads SSE from /api/ai/chat/stream
├── lib/                     # api.ts (contact form), i18n.ts, utils.ts
└── store/authStore.ts       # JWT in localStorage['token']
```

`public/` holds `cv.pdf`, profile and logo images, project screenshots (`projects/`), favicons, `robots.txt`, `site.webmanifest`, the Google Search Console verification file, and `oneko.js` + `oneko.gif` (the cat that follows the cursor). The sitemap and `content-snapshot.json` are generated by `scripts/prerender.mjs`.

## 3. Content flow

1. Khoi edits content in the admin console; it is saved in the database.
2. `scripts/export-content.py` reads the API and writes `src/content/portfolio.json` + `projects.json`.
3. `npm run build` prerenders every public page from those files (no content request at runtime) and writes `content-snapshot.json`.
4. `scripts/publish-content.sh` runs after every deploy and every 30 minutes (`.github/workflows/publish.yml`): if the API differs from the live snapshot, it rebuilds only the frontend container.

The files in the repo are the fallback for local development and a first deploy.

## 4. Conventions

- Always call the API with a relative `/api/...` path: in dev Vite proxies to `localhost:5000`, in production the frontend container's Nginx proxies to `backend:8080`.
- The admin console is code-split into **one** lazy bundle so visitors never download it. It is in Vietnamese and uses the site's tokens.
- Chatbot: `sessionId` is stored in `localStorage['ai_chat_session_id']`, with a `websiteTrap` honeypot.

## 5. Container Nginx (`nginx.conf`)

| Location | What it does |
| :--- | :--- |
| `/api/ai/` | POST rate limit 20 r/min, buffering off for SSE, 120s timeout |
| `= /api/contact/messages` | POST rate limit 5 r/min |
| `= /api/auth/login` | POST rate limit 10 r/min |
| `/api/` | plain proxy |
| `/assets/` | cached 1 year, immutable (hashed files) |
| `/projects/*.webp,jpg` | cached 30 days (linked with `?v=N`) |
| other static files | cached 1 day + stale-while-revalidate |
| `= /content-snapshot.json` | `no-store`, `noindex` |
| prerendered pages | `s-maxage=120` for the Cloudflare cache rule |
| `/login`, `/dashboard` | app shell, `X-Robots-Tag: noindex` |
| anything else | real file or the static 404 page |

## 6. Commands

```bash
cd src/Web/frontend
npm install
npm run dev      # http://localhost:5173, proxies /api → localhost:5000
npm run build    # tsc -b && vite build → dist/
npm run lint     # oxlint
```
