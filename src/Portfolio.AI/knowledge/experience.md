## 2. 2024 - 2025: Software Engineer (.NET) - Đội ngũ phát triển Sản phẩm SaaS

  - Thiết kế và triển khai kiến trúc Multi-tenant an toàn với Row-Level Security (RLS) trên PostgreSQL và SQL Server.
