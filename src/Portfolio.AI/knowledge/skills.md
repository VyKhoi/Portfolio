# KỸ NĂNG CHUYÊN MÔN & TECH STACK CỦA ANH KHÔI

## 1. Backend Core (Sở trường chuyên sâu của anh Khôi)
- **C# / .NET 8 / .NET 9**: Chuyên sâu ASP.NET Core Web API, Asynchronous Programming, Parallelism, Thread-safety, Concurrency.
- **ORM & Data Access**: Entity Framework Core, Dapper (viết query tối ưu tốc độ cao).
- **Kiến trúc phần mềm**: Modular Monolith, Clean Architecture, CQRS, Repository Pattern, RESTful API Design.

## 2. Cơ sở Dữ liệu của anh Khôi
- **PostgreSQL**: Thiết kế schema chuẩn, Indexing, Transaction, Row-Level Security (RLS).
- **Microsoft SQL Server**: Stored Procedures, T-SQL, Query Execution Plan Tuning.

## 3. Realtime, Caching & Message Queue
- **SignalR**: Kết nối hai chiều realtime (WebSockets).
- **In-Memory Caching & Distributed Caching**: MemoryCache, Redis.
- **Async Processing**: .NET Channels (`System.Threading.Channels`), BackgroundService.

## 4. DevOps, Hạ tầng & AI
- **Containerization**: Docker, Docker Compose, Multi-stage builds.
- **Hệ điều hành**: Linux Ubuntu Server, Windows Server.
- **CI/CD**: GitHub Actions tự động build và deploy lên máy chủ.
- **AI Tích hợp**: Local LLM với Ollama (Qwen 2.5), Prompt Engineering, RAG mindset.

## 5. Frontend & UI
- **React 19, TypeScript, Vite**.
- **Tailwind CSS v4**, Framer Motion, Zustand State Management.
